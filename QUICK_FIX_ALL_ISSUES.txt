ISSUE 1: No "Recurse" Checkbox in cPanel
─────────────────────────────────────────────────────────────
✅ SOLUTION: Use SSH Terminal (10 seconds!)

1. Login to cPanel
2. Find "Terminal" in "Advanced" section
3. Copy and paste this ONE command:

cd ~/public_html && find . -type d -exec chmod 755 {} \; && find . -type f -exec chmod 644 {} \; && chmod 775 uploads uploads/images logs cache && echo "✅ Done!"

4. Press Enter
5. Done! All permissions set in 10 seconds!

SEE: SSH_QUICK_SETUP.md for details


ISSUE 2: SSH Access Setup (Easiest Method)
─────────────────────────────────────────────────────────────
✅ SOLUTION: cPanel has Built-in Terminal!

No setup needed! Just:
1. cPanel → "Advanced" section → "Terminal"
2. Terminal opens in your browser
3. Run commands instantly

Alternative if no Terminal:
- cPanel → Search "SSH Access"
- Enable SSH keys
- Use Terminal app or PuTTY
